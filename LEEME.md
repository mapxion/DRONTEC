# Drontec — portada visual y dos servicios

Tres páginas estáticas: inicio, inspección técnica y fotogrametría.
Abre web/index.html para revisar la web localmente. Las imágenes, estilos y navegación están incluidos.

## Actualizar GitHub y EasyPanel

Sube el contenido de web/ a la carpeta web del repositorio mapxion/DRONTEC, sustituyendo los archivos anteriores y añadiendo las dos páginas nuevas y las imágenes. Conserva los nombres de las carpetas. Después pulsa Implementar en la aplicación web del proyecto drontec en EasyPanel.
Dockerfile y easypanel/nginx.conf se incluyen con la misma configuración del despliegue anterior.

## Edición

- web/index.html: portada visual con dos servicios.
- web/inspeccion-tecnica.html: torres, estructuras y telecomunicaciones.
- web/fotogrametria.html: ortofotos, nubes de puntos y modelos 3D.
- web/styles.css y web/app.js: aspecto y menú móvil.
- web/assets/: imágenes ilustrativas con créditos y licencias en web/LICENSE-IMAGEN.txt.

El contacto utiliza el teléfono ya indicado, porque el correo del hosting anterior dejó de existir. No incluye formulario de envío.
No se ha publicado esta versión automáticamente.

La cabecera y el pie de las tres páginas utilizan el logo original facilitado por el usuario, en web/assets/logo-drontec.webp.

Fotogrametría incorpora las cuatro imágenes facilitadas por el usuario. Se muestran completas y se pueden ampliar. La portada utiliza la ortofoto y el modelo de elevaciones.

Inspección incorpora las seis capturas facilitadas: vuelo, ficha de estación, inventario, estructura, visor y mapa. Versiones WebP hasta 1920 píxeles y miniaturas hasta 960 píxeles; ampliación por enlace.
